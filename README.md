# FitLog

FitLog is a simple fitness planner made for people who want a clearer path through the week. It gives you a dark, focused workout library, a clean plan flow, and a smooth way to save lifts for later without overloading the experience.

## Technologies Used
- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- LocalStorage

## Key Features
1. Browse a full workout library with exercise cards and detail pages
2. Add workouts to Today’s Plan or save them for later
3. Keep your plan and saved list updated live in the navbar
4. Track workouts in My Plan with sorting, completion actions, and quick removals
5. Enjoy a responsive dark interface with loading feedback, toast notifications, and a custom 404 page

## Project Structure
- src/app — pages and routing
- src/components — reusable UI components
- src/lib — workout data and helper functions

## Getting Started
1. Install dependencies
   npm install
2. Start the development server
   npm run dev
3. Open the app in your browser at http://localhost:3000

## Build
npm run build

## Why It Feels Useful
This project is built to feel practical and easy to use in real life: quick to scan, easy to plan, and designed to keep training decisions simple instead of overwhelming the user.
